# Чек-лист ручной проверки безопасности Android (пункт 23)

Проверять на собранном APK после `android\build-apk.ps1` (Android 8+/13+ желательно).

## WebView и origin
- [ ] Приложение открывается, главный экран загружается (контент из `https://appassets.androidplatform.net/assets/index.html`).
- [ ] В `MainActivity` нет `allowUniversalAccessFromFileURLs(true)` и `allowFileAccessFromFileURLs(true)` (оба `false`).
- [ ] Ассеты отдаются через перехват `WebResourceRequest` для origin `appassets.androidplatform.net` (эквивалент `WebViewAssetLoader` без зависимости AndroidX в текущем bare-metal билде).

## Функциональность
- [ ] Поиск/загрузка данных (AniList, Kitsu), постеры и шрифты работают.
- [ ] Выбор файла (импорт/бэкап/медиа) работает.
- [ ] Сохранение резервной копии/медиа через системный диалог работает.
- [ ] Внешние `http(s)` ссылки открываются во внешнем браузере/приложении, не внутри WebView.
- [ ] Ссылки/поиск TikTok и share intent работают как раньше.
- [ ] Кнопка «Назад» (Android) обрабатывается приложением (`handleAndroidBack`), выход — только когда нечего закрыть.

## Уведомления
- [ ] Разрешение на уведомления запрашивается и состояние сохраняется.
- [ ] `ReleaseNotificationBootReceiver` объявлен `android:exported="false"` (проверить, что восстановление расписания после перезагрузки устройства работает; BOOT_COMPLETED — защищённая системная рассылка).

## Примечание
- Если после перезагрузки уведомления не восстанавливаются из-за `exported="false"` на boot-receiver, зафиксировать это как дефект и вернуть минимально необходимый экспорт только для этого компонента.
