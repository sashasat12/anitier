Что свернуть и что изменить

Пошаговый план внедрения без переписывания всего сразу.

База аниме

  • Свернуть: «Язык поиска», «+ Своя карточка», «Случайное» → меню «⋯»
  • Убрать из чипов: «Случайное» (перенести в меню)
  • Собрать: поиск + «Фильтры N» + «⋯» в одну строку
  • Сделать сворачиваемым: блок «Продолжить просмотр»
  • Счётчики: в навбаре показывать только > 0

Карточка тайтла

  • Главное: перевести секции в табы «Обзор / Сезоны / Серии / Моменты»
  • Сезоны: использовать новый групповой порядок по датам
  • Обзор: описание + жанры + теги + MAL
  • Мобильный: tabs закрепить под заголовком

Просмотрено / Планы

  • Сводка: тиры в одну компактную строку вместо блока карточек
  • Меню: Экспорт/Импорт/Статистика → «⋯»
  • Поиск: «Поиск в списке» + сортировка + фильтры

Скоро выйдут

  • Компактность: объединить фильтры в панель по кнопке «Фильтры N»
  • Действия: «Экспорт .ics» → «⋯»
  • Сброс: оставить в панели фильтров

Уведомления

  • Фильтры: оставить только 3 таба
  • Группировка: по дате (Сегодня/Вчера/...)
  • Действия: «Отметить все» в шапке

Мобильная версия

  • Фильтры: bottom-sheet над нижней навигацией
  • Табы карточки: горизонтальные, скролл при переполнении
  • Сезоны: горизонтальный скролл групп (как сейчас)
  • Навигация: счётчики только > 0
