# План разработки AniTier

Этот файл — очередь работ. В начале каждой сессии открой его и выполни **первый по порядку** пункт. После выполнения удали пункт целиком. **Номера не меняй и не перенумеровывай**: пропуски означают уже выполненные пункты. Новые пункты добавляй только в конец, со следующим свободным номером.

Если пункт слишком большой, разбей его на подпункты `12.1`, `12.2` — номер верхнего уровня при этом не меняется. Если пункт оказался неверным, не удаляй его молча: замени текст на решение и коротко объясни причину.

## Правила работы

- Язык продукта, коммитов и этого плана — русский.
- Без новых зависимостей и сборщиков. Только HTML/CSS/JS и существующие PowerShell-скрипты.
- Каждый багфикс и каждая новая чистая функция — с тестом в `tests/`.
- После правок: `powershell -ExecutionPolicy Bypass -File .\test.ps1`.
- Если менялись `index.html`, `mobile/`, `*.js` интерфейса или `styles.css` — пересобрать `AniTier-phone.html` и `AniTier.apk` (`build-phone.ps1`, затем `android/build-apk.ps1`).
- Один пункт — один законченный коммит. Сообщение по-русски, в императиве.
- Перед удалением пункта проверь, что тесты зелёные, а критерий готовности выполнен.

## Пункты




### 34. P2 — Импорт списка из AniList

Файлы: `core.js`, `app-render.js`/`app-ctrl-*.js`, `tests/import.test.js`, `README.md`.

Сейчас есть импорт из MyAnimeList и Shikimori, а пользователи AniList могут перенести список только вручную. AniList отдаёт экспорт JSON, обычно сжатый в `.json.gz`.

Готово, когда: файл `.json`/`.json.gz` читается через `DecompressionStream` (с понятным сообщением, если браузер не умеет), парсер в `core.js` покрыт тестами, предпросмотр показывает «новые / уже есть / не найдено», оценки превращаются в тиры с учётом шкалы (0–10 или 0–100), прогресс серий восстанавливается, добавление идёт только по кнопке, новых зависимостей нет.

### 35. P3 — Завершить разделение app.js и app-render.js

Файлы: `app.js`, `app-render.js`, `app-render-*.js`, `app-ctrl-*.js`, `tests/split.test.js`.

Шесть модулей (`app-render-cards/lists/screens/modals`, `app-ctrl-moments/settings`) — пустые заглушки, хотя подключены в обеих оболочках; `app.js` (~164 КБ) и `app-render.js` (~157 КБ) остаются монолитами.

Готово, когда: код карточек, списков, экранов, модалок и контроллеров настроек/моментов перенесён в соответствующие модули, пустых заглушек нет, дублирования нет; `tests/split.test.js`, `test.ps1` и визуальная регрессия зелёные; артефакты пересобраны. Если не влезает в один коммит — разбить на `35.1` (рендер) и `35.2` (контроллеры).
