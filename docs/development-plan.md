# План разработки AniTier

Этот файл — очередь работ. В начале каждой сессии открой его и выполни **первый по порядку** пункт. После выполнения удали пункт целиком. **Номера не меняй и не перенумеровывай**: пропуски означают уже выполненные пункты. Новые пункты добавляй только в конец, со следующим свободным номером.

Если пункт слишком большой, разбей его на подпункты `12.1`, `12.2` — номер верхнего уровня при этом не меняется. Если пункт оказался неверным, не удаляй его молча: замени текст на решение и коротко объясни причину.

## Правила работы

- Язык продукта, коммитов и этого плана — русский.
- Без новых зависимостей и сборщиков. Только HTML/CSS/JS и существующие PowerShell-скрипты.
- Каждый багфикс и каждая новая чистая функция — с тестом в `tests/`.
- После правок: `powershell -ExecutionPolicy Bypass -File .\test.ps1`.
- Если менялись `index.html`, `mobile/`, `*.js` интерфейса или `styles.css` — пересобрать `AniTier-phone.html` и `AniTier.apk` (`build-phone.ps1`, затем `android/build-apk.ps1`).
- Один пункт — один законченный коммит. Сообщение по-русски, в императиве.
- Перед удалением пункта проверь, что тесты зелёные, а критерий готовности выполнен.
